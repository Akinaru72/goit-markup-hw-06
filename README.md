# goit-markup-hw-06

Responsive page layout with a mobile menu and Retina display support.

- Create a repository **goit-markup-hw-06**.
- Clone the created repository and copy the files from the previous assignment into it.
- Build a responsive layout for all page elements according to **[homework #6](<https://www.figma.com/file/wuEpGhwCepGCOUw7mZFRac/Web-Studio-(Version-5.0)?type=design&node-id=570573-1472&mode=design&t=nSUcnqBK92tVgzcJ-0>)**.
- Set up **GitHub Pages** and add a link to the live page in the **About** section of the GitHub repository.

---

## Acceptance Criteria

### Project

- **A1** When viewing the page on any device with a width of `320px` or more, no horizontal scrollbar appears.
- **A2** The source code is formatted using **Prettier**.
- **A3** All images and text content are taken from the layout.
- **A4** The **[modern-normalize](https://github.com/sindresorhus/modern-normalize)** style normalizer is connected.
- **A5** The code is written following the guidelines of **[Code Guide](https://codeguide.co/)**.

---

### Responsiveness

- **B1** All pages have a `viewport` meta tag in the `<head>` section.
- **B2** The layout is implemented for three breakpoints: `320px`, `768px`, and `1158px`.
- **B3** All background and content raster images are responsive and support `x1` and `x2` pixel density screens.
- **B4** The `min-resolution` media feature is used for responsive background images.
- **B5** Styles are written using the **Mobile First** approach and the `min-width` media feature.
- **B6** Styles that are needed only within a specific range are placed in media queries  
  `(min-width: ) and (max-width: )` or only `(max-width: )`.
- **B7** There is no unnecessary duplication of styles in media queries.

---

### Mobile Menu

- **C1** Markup for all mobile menu elements is completed.
- **C2** Styling for all mobile menu elements is completed.
- **C3** The menu width matches the layout.
- **C4** The menu occupies the full viewport height.
- **C5** The menu is hidden by default.
- **C6** When the `is-open` class is added, the menu becomes visible.
